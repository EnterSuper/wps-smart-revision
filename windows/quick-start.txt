WPS 智能修订 1.3.0 — Windows 11 部署与使用

请把整个压缩包转发到 Windows 电脑，不需要在 Mac 上安装 Windows。

一、安装（无需 Python / Node.js / 管理员权限）
1. 右键 ZIP → 全部解压。不要直接在压缩包里运行。
2. 保存自己的文档，退出 WPS 文字、表格和演示。
3. 双击 install-windows.cmd，看到 Installed 表示安装完成。
4. 打开 WPS 桌面“文字”文档，顶部选择“智能修订 → Windows 自检”。
5. 文字和格式自检通过后，先在新建测试文档试用。
   自检会替换剪贴板，结束后必须重新复制要粘贴的段落。

二、使用
复制新段落 → 选中原稿的一段正文 → 含格式智能粘贴。
仅修改文字、沿用原稿排版时，用“仅文字粘贴”。
Ctrl+Z 撤销整次操作；Ctrl+S 保存。Ctrl+V 仍是 WPS 普通粘贴。
日常修订模式使用 WPS“审阅 → 修订”；插件不再提供重复开关。
专用快捷键需从“开启快捷键”单独启用；不做自动历史存档，不上传正文。

三、完整教程
双击“部署与使用教程.html”或 README.html，在浏览器离线阅读。
包含测试示例、格式范围、保存与修订说明、更新、排错和卸载步骤。
不要只复制 .cmd 文件；请保留 payload、payload.json、windows 文件夹。

四、更新 / 卸载
更新：退出 WPS 后运行新版 install-windows.cmd，并重新自检。
卸载：退出 WPS 后运行 uninstall-windows.cmd。
卸载只移除本插件注册，不删除文档、其他插件或备份。

五、验证范围
本包包含高亮、白色底纹等最新修复。
Mac WPS 已验证 15 种高亮颜色、取消高亮及常用格式组合的修订恢复。
白色高亮、图案和主题底纹、字偶距变更等仍有限制，详见教程。
Windows 安装脚本已做文件事务测试，但还没有真实 Windows WPS 验收结果。
最新版 WPS 的不同发行渠道不一定都提供 JavaScript 加载项能力。
必须以收件人电脑上的自检和示例测试结果为准；失败时复制诊断记录反馈。
