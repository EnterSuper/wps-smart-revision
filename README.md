# WPS Smart Revision · 智能修订

**整段粘贴，按字词留下修订。** 面向 WPS 文字的本地加载项：复制改写后的段落，选中原文，智能粘贴会保留相同内容，把变化写成 WPS 原生修订。

支持 macOS；提供 Windows 11 适配与安装包。**Windows 原生 WPS／快捷键仍待实机验收。** 非金山官方产品，与 WPS、Microsoft、OpenAI 无隶属关系。

## 能做什么

- 中文按字、英文按词组对齐，避免小幅改写显示成整段删增。
- 默认带入已支持的富文本；另有仅文字粘贴。
- 支持常见字体、字号、加粗、斜体、下划线、字色、15 种标准高亮及取消、上下标、普通纯色底纹，以及部分段落格式。
- 结果可在 WPS 中接受、拒绝，并将整次操作一次撤销。
- 有专用快捷键辅助程序；只在 WPS 位于前台时启用，不接管普通粘贴。
- 无 AI API、无网络上传、无自动存档；不主动保存文档。

一次处理一段普通正文，不是全文比较器，也不支持所有 WPS 修订类型。大幅重写、语句重排仍可能显示较长删增。

## 安装与使用

从仓库 **Releases** 下载对应系统 ZIP，完整解压。

**Mac**：运行 `安装或更新.command`（需 Python 3），保存自己的文件并重开 WPS。若从源码安装，先执行 `sh shortcuts/build-mac.sh` 构建辅助程序；发布包已附通用二进制。

**Windows 11**：退出 WPS，运行 `install-windows.cmd`，重开 WPS 后先点击 **智能修订 → Windows 自检**。自检在临时文档中验证，失败的功能不会用于正文。无需 Node.js 或 Python；快捷键辅助程序由内置 .NET Framework 编译器生成。

日常操作：

1. 复制修改后的新段落；从 WPS 复制可携带富文本。
2. 在正文选中原段落或其中一部分。
3. 点击 **智能修订 → 含格式智能粘贴**；只改字时使用 **仅文字粘贴**。
4. 在 WPS“审阅”查看结果；Cmd/Ctrl+Z 撤销，Cmd/Ctrl+S 保存。

原生修订开关仍由 WPS 管理。插件只在本次写入中开启必要的修订，结束后恢复原开关。复制段落对齐、缩进等格式时，需包含来源段落标记；普通字符格式不需要。

## 快捷键

| 操作 | Mac | Windows |
| --- | --- | --- |
| 含格式智能粘贴 | ⌃⌥⌘V | Ctrl+Alt+Shift+V |
| 仅文字粘贴 | ⌃⌥⇧⌘V | Ctrl+Alt+Shift+B |

先点 **开启快捷键**。Mac 还需打开发布包中的 `shortcuts/SmartRevisionKeys.app`；Windows 入口尝试启动托盘辅助程序。辅助程序提供备用 F9 / F10 组合与暂停／退出，不加入开机启动。

详见 [快捷键部署、冲突与停用](docs/SHORTCUTS.md)。Mac 含格式快捷键已完成用户实际按键和原生修订生命周期测试；Windows 与备用组合须对应机器验证。

## 明确的限制

- 单次最多 12000 个 UTF-16 字符；跨段落、表格、列表和复杂排版不在验证范围内。
- 与域、书签、脚注、公式、图片、批注、内容控件等结构相交时停止。拒绝处理这些结构不等于支持编辑它们。
- 白色“高亮”编号 8 不支持；普通白色底纹是另一种格式，已支持。主题／图案底纹及未映射格式不静默丢弃。
- 禁止通过本工具改变字偶距 Kerning，因为混合格式测试曾发现原生单次撤销不能完整恢复。
- 同一选区反复改写会以尚未接受的文字修订之前的内容重新对齐；重建选区文字修订时使用当前作者和时间，不保留逐轮作者链。
- 不解释 AI 输出中的 Markdown。只有真实富文本剪贴板携带的格式才可映射。
- 提示恢复无法确认时，应停止继续操作并检查文档；这不是成功提示。
- 不同 WPS 发行渠道可能未开放 JS 加载项接口。“最新版”不自动等于兼容。
