# 智能粘贴快捷键

先复制改写后的段落，再在 WPS 正文选中原段落。快捷键调用与工具栏相同的修订入口。

| 操作 | macOS 默认 | Windows 默认 |
| --- | --- | --- |
| 含格式智能粘贴 | Control + Option + Command + V | Ctrl + Alt + Shift + V |
| 仅文字粘贴 | Control + Option + Shift + Command + V | Ctrl + Alt + Shift + B |
| 备用组合 | Control + Option + Command + F9 / F10 | Ctrl + Alt + Shift + F9 / F10 |

辅助程序只在 WPS 位于前台时注册这些组合。普通 Cmd+V / Ctrl+V 保持原样。系统已占用的组合注册失败时不会强行覆盖；WPS 内部命令或其他工具仍可能冲突，请从“修订”菜单栏／托盘菜单切换备用组合。Mac 的功能键可能需要同时按 Fn。

## Mac

1. 完整解压 Mac 发布包，执行 `安装或更新.command`。需要 Python 3；源码构建另需 Xcode Command Line Tools，发布包已附 Intel/Apple Silicon 通用辅助程序。
2. 保存自己的文档，正常退出并重开 WPS，载入新版工具栏。
3. 点击 **智能修订 → 开启快捷键**，启用加载项接收。首次开启后，后续启动 WPS 会恢复接收。
4. 在解压目录打开 `shortcuts/SmartRevisionKeys.app`（WPS 修订快捷键）。菜单栏显示“修订”。它不加入登录启动项，也不要求辅助功能或输入监控权限。
5. 回到 WPS 的新建示例，复制改写、选中原文，按快捷键。先用示例确认结果，再用于正式文件。

WPS 的 Mac 执行接口未能可靠启动辅助程序，因此使用单独双击启动，不声称一个按钮会完成所有步骤。若系统对未签名应用给出拦截，按组织策略处理，不要关闭系统安全保护；源码可自行构建，工具栏功能不依赖辅助程序。

## Windows 11

1. 完整解压 Windows 包，退出 WPS，运行 `install-windows.cmd`。
2. 安装脚本使用 Windows 自带 .NET Framework 编译器生成托盘辅助程序，不需要 Node.js、Python、Visual Studio 或额外运行时。若编译器不可用，安装程序会提示，工具栏入口仍可用。
3. 打开 WPS，先运行 **Windows 自检**，然后点击 **开启快捷键**。若 WPS 询问是否运行程序，核对为本插件的 `SmartRevisionKeys.exe`。
4. 托盘图标可切换默认／备用组合、暂停和退出。首次在新建示例中测试。

**Windows 原生 WPS 与快捷键链路尚未在 Windows 实机验收。**安装成功、编译成功和离线测试均不等于实机验收。若没有托盘图标或按键无效，继续使用工具栏并反馈 WPS 版本和错误提示。

## 停止、保护与资源使用

- 点击工具栏 **停用快捷键** 停止加载项接收；从辅助程序菜单选择退出可释放热键。
- 不监听或记录普通按键，不读取剪贴板正文到辅助程序，不访问网络，不自动保存文档。
- 启用时每 200 毫秒检查一个很小的本地请求文件；空闲时不读取文档、不写心跳。选区变化事件只记录会话与序号，正文和文档名不写入通信文件。辅助程序约每 150–200 毫秒检查前台应用。
- 请求只在 1 秒内有效；重复、过期、忙碌或选区变化的请求会停止，不排队、不自动重试。
- 暂时切换文档／关闭弹窗后若首次按键没有执行，请重新选中文本再试。接收成功不代表修订完成，以 WPS 结果与提示为准。
- 加载项和辅助程序共享当前用户的三个固定小 JSON 文件，不累积正文或历史版本。它不是防御同一账号下恶意软件的安全边界。
- 本机测试：用户实际按下 Mac 含格式快捷键，回执完成；随后核验文字、加粗、高亮、接受、拒绝和严格 XML 单次撤销。Windows 与备用组合仍需对应机器实测。
